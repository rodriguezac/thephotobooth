# The Photobooth

Fotocabina web con cámara, filtros, diseños personalizados, descarga de tiras y QR para compartirlas mediante Cloudinary.

La aplicación está en `thephotobooth/`.

```sh
cd thephotobooth
npm install
npm run dev
```

Consulta [la documentación de la aplicación](thephotobooth/README.md) para configurar Cloudinary, compilar y ejecutar las pruebas. Los identificadores de la cuenta se configuran localmente con `.env.local`, siguiendo `.env.example`; la configuración local no se publica en este repositorio.
